# m-hub

本地优先的 macOS 桌面效率工作台。Bento 风格 Dashboard，Tauri 2 + Vue 3，数据全部留在本机 SQLite。

> **本仓库是私有分发仓库，只包含功能说明与安装包，不含源码。**

## 安装

从下面的 Releases 下载 `m-hub_0.7.3_aarch64.dmg`（Apple Silicon）。

打开 DMG 拖入「应用程序」。因为是自签名分发（未上架 Mac Store），首次打开若提示无法验证开发者，请到「系统设置 → 隐私与安全性」点「仍要打开」。

需要 macOS 12 及以上。

## 功能

### 工作台

自由编排的 Bento 网格。每张卡片可拖拽、调宽高、切换形态，布局自动持久化。

- **时钟** —— 三种形态：大时钟（时间 / 日期 / 天气 / 语录）、今日阴阳历（农历 + 干支生肖）、极简时间
- **天气** —— 简版（图标 + 温度 + 城市）/ 详情版（体感 / 湿度 / 风况），Open-Meteo 数据源
- **系统监视** —— CPU 与内存，2 秒轮询
- **便签 ×2** —— 600ms 防抖自动保存
- **倒计时** —— 支持一次性 / 每天 / 定时间隔，可暂停、可弹出独立圆窗（圆形水位动画 + 透明置顶）
- **待办** —— 清单视图，支持优先级、行内编辑、拖拽排序、删除撤销
- **日历** —— 月历上标出待办分布，含周期待办的虚拟实例
- **速记概览 / 待办概览 / 资源概览**
- **提示词百宝箱** —— 点击即复制，支持置顶与复制计数
- **最近使用通栏** —— 按最后启动时间排序
- **自定义速达** ×4 —— 内容可选「置顶的资源 / 应用 / 网页 / 文件 / 某一大类」，四槽位固定

带「布局编辑器」：所见即所得，画布内是真实组件（可交互的挂真实卡片、其余等比缩印），缩放系数按画布列宽与真实列宽实测比值计算。

### 待办

独立视图（宽窗左列表 40% + 右日历 60%，窄窗自动单栏）。支持标签筛选、月 / 周两种范围形态、周期待办、置顶、展开子待办、跨组拖拽排序。

**截止与提醒**：日期与时间一律用应用内控件（不用系统原生 `datetime-local`），日历格可拖拽改期。

**周期规则**：勾选「完成本轮」而不是勾掉 —— 截止日期自动滚到下一个未来时刻（逾期不补历史），累计次数 +1，子待办复位，本身不进已完成列表。规则可设结束条件（until / 累计次数），用尽后自动转回一次性并保留该行。

### 速记

Milkdown 所见即所得编辑器（Markdown 为真相源）。图片三路入口 —— 粘贴 / 拖拽 / 点击上传 —— 都落本地并按内容哈希命名去重，笔记里引用的是哈希路径，所以**换机、迁数据目录后图片仍然有效**。

### 速达

应用 / 网页 / 文件三类资源的统一入口。支持分类管理（各大类下再分小类，可拖拽排序、设默认）、批量扫描导入、拖拽导入、以及「在应用内打开网页」（独立标签页 + 自绘顶栏，不是把外部网页塞进主窗口）。

**运行中绿点**：能显示目标程序是否在运行，识别应用包路径而不仅是进程名。

### 剪贴板历史

文本 / 图片 / 文件三类记录，置顶、搜索、过期清理、图片导出（截图类应用只往剪贴板写 BMP，存 PNG 时会真正重编码并修掉 alpha 未初始化问题）。

**焦点归还**：粘贴后自动切回你原先在用的那个应用 —— 按 bundle id 匹配，不是按进程名（两者在 macOS 上不是一回事）。

**Esc 关闭**：用系统级事件监听兜底（无激活显示的浮窗收不到普通按键），且所有收起路径都会正确停止监听。

### AI 对话

OpenAI 兼容的流式对话（Ctrl+Shift+K）。可内嵌抽屉，也可作为独立小窗（可拖动 / 置顶 / 隐藏到后台）。

API Key 存系统钥匙串，**不明文落盘**，界面脱敏。供应商 / 模型可自管。

> 平台 AI 额度需要 m-hub 服务端，本仓库不提供该服务，故平台相关入口当前不可用。

### 扩展系统

四种形态：`module` / `view` / `window` / `drawer`，另有 service 形态（扩展自带 Node 后端，宿主托管进程与端口）。

- **扩展中心** —— 三个标签页：已安装 / 市场安装 / 我的扩展（本机源码目录直挂，登记即加载、有热重载）
- **能力注册表** —— 桥 API 集中在静态表里，新增能力 = 加一行 + 写 handler；`runtime.info` 返回清单供扩展自检
- **权限系统** —— 按能力逐项授权，可在扩展详情里查看与回收
- **配置分层** —— manifest 里的作者默认值 + 用户 `.config.json` 覆盖层，升级扩展不会冲掉用户设置
- **跨扩展协作** —— 事件总线 + 显式 `expose` 白名单的跨扩展调用
- **独立 origin** —— 扩展内容走独立自定义协议，与承载用户数据的协议跨源；资产作用域只放行白名单子目录

### 壁纸与外观

三轴主题：模式（亮 / 暗 / 系统）× 预设（10 单色 + 10 渐变）× 强调色（8 预设 + 自定义）。

壁纸导入后自动做背景模糊 + 可调蒙版，扩展页面底色会跟随（扩展可以铺自己的背景，不会被挡住）。

### 自动更新

应用内自研更新链路：静默检查 → 验签 → 下载 → sha256 校验 → 重启替换。

支持断点续传、自动退避重试、跳级保护、跳过某版本、稍后再提示。

macOS 上替换的是**整个 `.app` 包**而不是单个二进制 —— 只换内层二进制会破坏包签名，Gatekeeper 随即拒绝启动。替换失败会自动回滚。

## 数据与隐私

- 全部数据在本机 SQLite，无任何遥测、无云同步
- 备份 / 恢复走「复制到暂存 → 校验 → 原子替换 → 才删旧」，失败完整保留原件
- 恢复要么完整成功，要么完全没发生，**没有中间态**

## 已知限制

- 平台账号登录、AI 额度、扩展发布需要 m-hub 服务端，本仓库不提供 → 当前不可用
- 本地 GitHub 登录可用（不经过服务器）

## 系统要求

macOS 12+，Apple Silicon / Intel 均可（发布包为 aarch64）。
